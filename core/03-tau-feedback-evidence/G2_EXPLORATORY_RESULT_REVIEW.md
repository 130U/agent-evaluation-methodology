# G2 探索性案例：独立结果审查

## 结论

两臂均完成预登记的执行终点，四次真实任务运行均获官方满分，独立研究代理逐条核查后也判为合格。但两臂均停在 `skipped_all_perfect`：训练样本已满分，GEPA 按原设置跳过反思，最终策略仍为 S0。本次没有反思调用、候选生成或候选评价的真实执行证据，不能据此认定 GEPA 优化成功或反馈准入带来收益。

两次原生 reviewer 均未产生 Agent 诊断，原始反馈池和所选反馈池均为空，B2 的 gate 实际调用为 0。因此本案例也不能评价准入准确性、建议保留损失或收益。

## 范围与执行

训练为 task 85（structural_43），开发验证为 task 75（structural_35）；两题此前均用于开发，且在已知 G1 结果后选定。两臂各自重新生成基线轨迹，依次运行 B1、B2，模型为 gpt-5.6-sol / low，采用预登记的 HTTP 文本适配。仿真种子为 43、优化器种子为 0，模型采样种子不可控。这是已知开发案例，不能解释为配对因果比较、未见任务表现或原 G1 自然收益比较的恢复。

S0 原文：

> Follow the retail policy. Help the authenticated customer complete their request using the available tools, and accurately communicate the outcome.

每臂预登记 1 次 proposal opportunity、最多 4 个 episode，保留满分跳过与严格改善接受规则；实际每臂只运行初始开发验证、训练评估各 1 次。训练轨迹进入原生诊断，返回空诊断后，官方 GEPA 满分跳过事件发生。两臂均未重试或强制生成候选。
