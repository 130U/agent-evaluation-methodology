# G3：真实候选、验证与最终测试

2026-09-17。**本轮已到终点：优化完成，最终测试按原规则停止。** 36次计划测试中18次完成评价、1次中断未评分、17次未运行；本版报告实际证据，不将停止等同于完整测试完成。

## 1. 本轮回答什么

G3沿用固定τ2/GEPA、订阅模型 `gpt-5.6-sol / low` 和相同S0。两臂各有一次候选机会、相同资源上限，分别生成自己的训练和验证轨迹。2训练、2验证、6测试；任务同源实体闭包不跨组。留出只指本轮在线优化流程，全体公开任务此前已静态审查。

登记时两臂均关闭GEPA满分跳过，仍要求训练严格改善。B1提供原生诊断；B2在相同载体中进行语义准入，再与动作来源/可修改范围资格取交集。最终测试前另做共同验收；不在测试上选策略。

## 3. 两个需要保留的观察

**训练改善不等于候选可以采用。** B1在task76从失败变为成功，另一训练题仍成功。但初始运行中用户只提出删除单件商品和还有其他问题；候选运行的开场披露了三个具体目标。两次是完整新运行，用户展开与模型抽样也变了，不能把1/2→2/2唯一归因给提示修改。

**官方满分不覆盖所有客户承诺。** B1候选验证task16正确完成两项取消、一项退货申请和8276.23总金额。最后答复却把5–7工作日概括给全部PayPal退款；政策只为取消退款提供这一时限，退货工具仅确认申请和邮件指引。两位审查者均判为普通语义失败，未升级为关键违规。于是候选官方验证仍为2/2，独立合格检查为1/2，原S0为2/2。当前官方NL断言没有检查这项额外承诺。

B1原生诊断还把task76私有场景中的取消备选、滑板要求与历史金额问题，当成用户在转接前已经明确提出的内容。整体任务未完成有依据，但具体责任判断需要按行动时可见信息核对。这不证明其中所有建议无效；可执行的改进建议与有根据的错误指责仍需区分。

## 4. 冻结选择与登记后修正

GEPA保留S0时，原选择脚本把S0文本与新候选验证行放在同一候选身份下，触发正确的hash矛盾拒绝。红队独立复现此可达路径；单独的v2封存器仅修正记录绑定，保留GEPA的 `selected_new=False`，没有更改阈值、任务或重跑。原脚本及945个冻结源仍与原manifest相同。详细时点和5项回归见 [修正说明](../../supporting-evidence/tau-feedback-evidence/research/G3_SELECTION_BINDING_AMENDMENT.md)。因此不能声称全部选择和报告实现都在运行前冻结。

B1最终未被GEPA选为best；共同验收同时记录了验证合格数不足及task16的普通回归。验证输入＋输出token比为1.08155，未超过1.25阈值，但成本合格不能抵消质量条件。不能说共同验收单独阻止了GEPA原本会采用的候选，因为GEPA已经保留S0。

B2候选没有验证运行，相关缺失状态不代表它在验证集实测失败。B2没有原生诊断进入gate，候选由共同公开政策反思生成；本轮未激活反馈筛选差异，不能估计语义准入或来源筛选的任务收益。

另有明确的满分起点限制：B1的S0验证合格2/2，无法在同一二题验证集上严格提高；即使不存在退款承诺问题，也不满足共同验收的严格改善条件。B2父代训练2/2同样没有二元训练分数的提升空间。这限制本轮识别机制增益，不是“反馈机制普遍无效”的证据。

最终策略文件SHA256 `75bbab0ceaf5c27d3262122fcb89ca04db637426a570d033fc9f28e39c944567`。B0/B1/B2最终文本完全相同，SHA256均为 `86aa62048c4845c3564aba229035c6bab5cbe20057b36108abbb5c8407ac0961`。该文件在首个最终测试调用前已生成并核对。

## 6. 最终测试与结论范围

预分配36单元：6题×2次×3组。第一轮18次全部完成；第二轮首个单元task79/B1的模型连接发生网络错误，CLI重连后虽返回输出，固定校验仍拒收，研究按STOP结束。没有运行器补跑或追认接受。原因、费用与273次原始调用核对见[停止审计](../../supporting-evidence/tau-feedback-evidence/research/G3_TEST_STOP_REVIEW.md)。

“已核验合格”同时要求官方/结构通过、语义合格、用户有效且无关键违规。B2的unit016两份审查均认为语义失败，但用户有效性未知、关键违规意见不一致，因此整体状态按既定规则保留unknown。不能把合计12个已核验失败写成13个，也不能把未知并入失败。三组task62均官方满分，却都回答了涉及用户或工具未提供知识的零售范围外诗歌问题，语义审查均失败；这支持额外语义覆盖的具体必要场景，不是一般错误率估计。

18条只覆盖第一轮，预定pass²为不可估计。官方成对结果有1个B1成功/B2失败，但策略相同，且6对未决；合格成对结果另有用户有效性未知，共7对未决。完整修复率、回归率、配对差及全计划单位合格成本均留空。报告中已确认成功/12是固定分配分母上的已知比例，不能冒充完整测试成功率。

本轮实际执行了“反思—候选—新运行—验收—保留旧策略”。结果支持一个明确的方法结论：**任务得分、错误归责与策略采用必须分别核验；训练得分提高或官方满分，不足以支持采用新策略。** 来源资格检查有可复核的失效案例与受控依据；它的净性能收益仍无法从本轮识别。两臂均保留S0、B2筛选未激活、起点满分、用户披露差异和最终测试中断共同限制了因果与泛化结论。
