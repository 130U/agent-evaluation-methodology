# τ-bench：面向反思式优化的反馈归责与证据准入

研究基础：基于τ2-bench文本零售任务与GEPA反思式优化，搭建任务执行、失败诊断、策略生成与回归验收流程，研究反馈成为可靠更新依据所需的条件。

问题发现：源码审计与真实运行发现，框架预置行为可能被误归责于Agent；官方满分也未必覆盖候选策略作出的额外承诺，得分、责任与更新质量需要分别判断。

机制设计：建立证据约束的反馈准入机制，核对评价完整性、行动时信息及策略可修改范围，再以独立语义复核和共同回归门槛决定候选能否被采用。

研究结论：固定合成校准中，来源核对额外拦截了语义审查接纳的框架误归责，但组合准入仍会放行证据不足的反馈；研究建立了可复核的改进路径，尚未证实任务成功率提升。
