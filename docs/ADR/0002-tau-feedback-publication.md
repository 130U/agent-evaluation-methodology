# ADR 0002：以 τ-bench 反馈有效性研究作为当前主线

- 日期：2026-09-18
- 状态：已采纳
- 依据：作者明确要求发布当前研究、对齐项目截图，并删除旧 ALE 专题。

## 决定

首页与当前项目卡使用截图中的完整标题、2026.05 - 2026.08 展示周期和四条摘要。ICFA 作为文字报告副标题，说明命名与理论整理日期。实验记录保持其真实日期。

沿用核心报告与支撑证据分区；2026-09-17 封存的 202 份公开材料逐字节保留。新增当前报告和导航，不倒写旧协议、日志或导出状态。

移除当前版本中的旧 ALE 独立专题及其直接配套材料，保留不相关的辅助界面资料。ALE 名称仅保留为截图要求的基准背景。历史版本通过 Git 提交记录查阅，不执行历史重写。

## 影响

读者从当前项目卡进入完整报告，再查看封存实验与复现代码。历史导出清单描述导出时点；当前机器可读清单单独记录发布文件、哈希与删除范围。

本决定替代 ADR 0001 的 ALE 项目导航安排，继续保留核心报告与支撑证据分离的原则。
