# 公开材料与复现边界

本仓库公开研究报告、固定来源信息、实现与测试、离线控制结果，以及经过筛选和脱敏的真实交互摘要。

公开材料不包含账号登录信息、API 密钥、原始订阅会话日志、本机缓存、完整运行目录或未获公开授权的材料。文中涉及的第三方任务、政策与依赖按[第三方说明](../supporting-evidence/tau-feedback-evidence/THIRD_PARTY_NOTICES.md)保留来源及许可。

## 复现层次

1. **材料核验：**公开文件可与封存导出清单的 SHA-256 对照。
2. **组件复现：**按[复现包说明](../supporting-evidence/tau-feedback-evidence/README.md)安装依赖并执行适用的离线测试。
3. **交互研究：**模型、传输方式、模拟用户和环境均参与结果形成；公开摘要不等同于全部原始运行材料。完整条件见[复现边界](../supporting-evidence/tau-feedback-evidence/PUBLIC_REPRODUCTION_BOUNDARY.md)。

组件校验通过只说明对应规则在所测输入上的行为，不自动证明 Agent 任务成功率提高。合成反馈与真实交互采用不同的证据口径。展示周期、实验记录日期和方法命名日期分别保留。

当前发布范围与历史专题移除记录见[发布清单](../supporting-evidence/UPLOAD_MANIFEST.md)。
