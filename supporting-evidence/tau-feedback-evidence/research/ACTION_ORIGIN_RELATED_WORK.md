2026-09-17。补充检索发生在 N1 揭盲和 E4 假设形成之后；用于限定论述，不作为实验前已知依据。以下为作者原始论文的摘要级核验，没有复现其效果，也不据此断言全文没有相同细节。

| 工作 | 已公开的方法 | 对本研究主张的约束 |
|---|---|---|
| [CAST，2026-08-31](https://arxiv.org/abs/2608.30147v1) | 在部分可观测条件下构造动作级批评，用于 critic 与 policy 训练 | 行动级、可见信息约束及 critique 学习已有先例 |

| [CANTANTE](https://arxiv.org/abs/2605.13295) | 比较同一问题下不同联合配置的轨迹，将整体回报转成各 Agent 的更新信号 | 不能把组件级归责或反事实比较本身称作原创 |
| [AgentGrad，2026-09-08](https://arxiv.org/abs/2609.08572v1) | 逐个干预 Agent 行为，检验修改哪个组件能解决失败，再构造细粒度反馈 | “修改对象必须能够影响失败”已有直接研究；本项目不是首次提出干预有效性 |
| [HarnessEvolve，2026-09-01](https://arxiv.org/abs/2609.00829v1) | 参考轨迹辅助诊断，并以质量与性能两层验收约束 harness 更新 | 执行、诊断、更新及回归验收的分工已有系统实现 |

## 本项目能够增加什么

现有实验证据支持一个更窄的贡献：在固定 τ2—GEPA 接入中，发现语义 gate 把框架预置 assistant 消息归给待优化策略；用实际调用对应关系和无生成的初始化控制复核该错误，并实现来源证据不足时弃权、框架动作转交框架审查的规则。

这里验证的是 **某条记录是否属于本次策略干预范围**，而非哪个策略修改能改善整个任务的因果估计。163 条模型来源动作仍需政策和语义审查；18 条框架来源消息不是 18 条错误诊断。该案例与改进实现有独立工程价值，但不足以宣称新颖性已获学术认可，或优于上述方法。

公开论文应将其定位为可复现的评测失效案例与反馈准入研究，并用额外任务、不同框架和真正独立标注检验适用范围。不要将已有归责原则重新命名后当作新算法贡献。
