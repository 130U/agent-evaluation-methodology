# 选择性反馈准入：实现与待验证命题

状态：机制实现草案，尚未运行语义判断或优化对照；不属于已冻结 G1 基线配置。G1 只判断本机模型与模拟用户能否承载后续研究。

## 研究增量放在哪里

τ2 已有逐条 reviewer 诊断、责任来源和错误位置；GEPA 已有轨迹反思与候选验证；CAST 已有依据行动时可见信息进行批评的原则。本项目不把这些能力重新命名为原创。要检验的增量是：**当已有 reviewer 产生了诊断，是否值得先判断哪些诊断足以指导策略更新，并允许拒收或弃权？**

选择性准入可能减少错误建议，也可能丢掉有效建议、消耗预算，甚至让优化变差。因此结论必须同时解释错误流入、有效反馈保留、验证成本与最终任务表现。不能用拒收数量替代优化收益。

来源：[固定 τ2 reviewer](https://github.com/sierra-research/tau2-bench/blob/2174a603f6d014ef94473ffa95957f6ce27100db/src/tau2/evaluator/review_llm_judge.py)、[GEPA](https://arxiv.org/abs/2507.19457)、[CAST](https://arxiv.org/abs/2608.30147)。

## 当前实现

`src/tau_feedback/admission.py` 接收一条原生诊断、实际轨迹、政策和工具定义。接口不接收隐藏任务说明、参考动作或最终目标状态。

1. **先核对对象。** 非 Agent 来源、缺少诊断或改正建议、错误位置不唯一，均弃权；不能猜测 reviewer 指的是哪个动作。
2. **重建可见证据。** 按真实 `turn_idx` 找到动作，只保留动作之前的消息、该动作、政策及工具定义；剥离 raw model data 等额外字段。
3. **判断三件事。** 诊断是否被证据支持、责任是否属于 Agent、改正行为是否能依据当时信息决定。这里需要语义模型，当前并未证明判断可靠。
4. **执行保守准入。** 三项全部为真、输出结构完整、引用能定位，才准入；明确反证则拒收，不确定则弃权。引用可定位只是一项结构要求，不证明语义蕴含。
5. **保持干预单一。** 准入后保留原诊断文字，不让准入器另写更强建议。拒收和弃权的诊断及理由不进入反思输入；原始记录仍留在审计文件。

当前实现使用本地哈希发现意外串档，不构成恶意环境下的来源认证。judge 请求和响应应由调用者写入原始账本；每次判断均消耗相应实验组的预算。模型异常不得当作零成本或默认准入。

## 与 GEPA 接口的衔接约束

语义核查应在实例信息清理之前执行，以保留精确动作与证据位置；反思数据清理则在之后执行，防止把订单、用户或答案标识写进长期策略。不能让当前 adapter 中的数字清理破坏索引后，再假称完成了精确证据定位。

两组应共同采用逐条原生错误记录的载体，避免 B1 提供全文 summary、B2 只提供 error list 而引入额外差异。B2 的过滤回调只输出已经绑定、已准入的原生诊断。全拒收时返回明确的空反馈状态，不能自动回退到原始诊断。即便没有诊断，优化器仍可能从得分和输出推断原因；本研究不声称能禁止其所有自主推断。

`gepa_adapter.py` 已提供固定策略入口和显式过滤器接口；真实 episode、原生 reviewer、准入器、反思模型及总预算之间的完整调用尚需接好并验证。不能把接口单测写成一次实际 GEPA 优化。

## 最小对照与解释范围

| 实验组 | 用途 |
|---|---|
| B0 原始策略 | 描述起点与未优化表现 |
| B1 GEPA + 原生 reviewer 逐条反馈 | 主要优化对照；这是本项目接入的基线，不冒称官方自带的 τ2—GEPA 实验配置 |
| B2 同一 GEPA + 选择性准入 | 测量准入机制整体效果，包括额外验证成本 |
| 直接前缀 critique | 检验收益是否已被 CAST 类思路解释 |
| 等量随机筛选 | 检验是否只因反馈变少而改善 |
| 相同证据但不筛选 | 区分证据补充与选择动作的贡献；具体输入需在试验前另行固定 |

只有前三组时，最多讨论机制整体的探索性差异，不能把正结果归因到某个模块，更不能确立相对已有前缀 critique 的创新优势。各组总账应计入 Agent、用户、judge、reviewer、准入、反思、验证及重试；“候选数量相同”不代表成本相同。

## 评价与否证

- **反馈层：** 原生诊断的错误率、错误诊断准入率、有效诊断保留率、弃权率、各类责任混淆及每条判断成本。自然诊断与人为注入扰动分开报告。没有独立语义标注时，不把模型自评当准确率。
- **策略层：** 冻结候选后，以隔离的任务组评价完整合格完成、重复完成、已有成功任务的回归及全部角色成本。先报告逐任务配对结果和区间，再讨论总体变化。
- **否证条件：** 相对 B1 没有收益、收益被随机筛选解释、额外验证成本抵消收益、有效反馈损失过高，或用户/评分异常主导结果，均应保留为负面或未决结论。
- **外部效度：** 本机 1.5B 量化模型的结果只覆盖该组合系统，不能外推到强模型、其他领域或生产客服。未见任务指优化过程隔离的任务，不保证预训练时完全未见。

当前可以主张的是：离线结构完整性缺口已被受控复现，本地真实推理与工具通道已经建立。选择性准入是否改善 Agent，仍需要上述证据链；不能从工程可运行直接推出。
